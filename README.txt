Delivery Dash - project files
index.html   page structure
style.css    styling
game.js      all game code (edit this one)
lib/         three.js + GLTFLoader (no internet needed)
assets/      delivery_car.glb, final_destination.glb, city_pack.glb

Open index.html through a web server / browser preview (the 3D models are
loaded as files). If a model can't load, the game falls back to simple boxes.
